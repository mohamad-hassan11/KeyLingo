# Phase 1 visual review

Warm cream, deep brown, burnt orange, gentle borders, and locally hosted Noto fonts
form the studio palette. Dark mode pairs warm brown surfaces with apricot accents. Desktop navigation sits beside the workspace; mobile
navigation scrolls horizontally. Arabic mirrors navigation and reading order,
while the physical keyboard stays left to right. Theme follows the device or an
explicit preference.

These are screen studies, not functional typing activities. Example text, metrics,
and charts are labeled illustrative and never saved. Content has not received
independent linguistic review and is not the released pilot corpus. Keyboard keys
are a geometry preview; complete mappings/finger guidance arrive in Phase 3.
The stacked mobile lookup study establishes typography and reading order; the
interactive mobile translation dialog and focus return arrive with Phase 4.

All five studies were checked for document overflow at 360, 768, and 1280 pixels
in English and Arabic. Nine images were captured; visual review covers desktop,
mobile, Arabic, and dark layouts. Arabic connected text, punctuation, and mixed
language blocks render naturally in these samples. This does not establish OS-level
IME correctness, screen-reader behavior, or a completed accessibility audit.

## Review gate

The user approved both the screen layouts and the implemented orange palette.
Phase 1 visual acceptance is complete. All nine screenshots show the approved
palette. Phase 2 separately implements the deterministic engine and minimal
native-input harness; its authorization and later milestones remain separate.
